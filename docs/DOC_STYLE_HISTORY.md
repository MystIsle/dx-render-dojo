**칠 코드는 펼치고 CMake 는 소스를 모음 (2026-09-25)**

곁가지 분량 규칙(2026-09-23)이 따라 치기 원칙(2026-09-24)보다 먼저 생겨서 "따라 하기에 필요한 코드라도 접음" 이 남아 있었습니다. 코드를 모두 따라 치게 된 뒤로는 칠 코드를 접을 이유가 없었고, 점선 접기로 구분해도 매번 열어야 했습니다.

- 2절 곁가지 규칙을 "학습 블록 없음, 풀이와 개념 상자만 접음, 칠 코드는 펼침" 으로 바꿈. 7절의 `fold must` 는 없앰
- CMake 는 `file(GLOB_RECURSE ... CONFIGURE_DEPENDS Source/*.cpp)` 로 소스를 모음. 새 파일마다 치던 CMake 조각이 없어짐. VS 는 IDE 에서 파일을 넣으므로 그대로. 셰이더 복사도 `file(GLOB ...)` 으로 모음
- CMake 조각은 `CMake · 맥 빌드와 검사용, VS 만 쓰면 건너뜀` 접기로 옮김. 따라 하기의 기본 경로는 VS
- 이력을 01편 셋업 커밋부터 다시 써서 모든 태그의 `CMakeLists.txt` 가 바뀜. 코드와 프로젝트 파일은 그대로
- 04편을 7단계 커밋으로 다시 쌓음. 순서 : DirectXMath → RTV·뷰포트 → 버퍼 → 셰이더 컴파일 → 삼각형 → 상수 버퍼 → 카메라. 5단계는 행렬 없이 그려서 삼각형이 창을 채우고 창 비율을 따라 늘어나고, 6단계는 세 행렬을 항등으로 넘겨 5단계와 모양이 같음. "새 파일을 빌드에 등록한다" 단계는 없애고 단계마다 등록함. `external/DirectXMath` 는 1단계 커밋에 넣음
- 기각 : 상수 버퍼와 카메라를 한 단계로. 상수 버퍼·전치·투영이 한꺼번에 오고 중간에 확인할 화면이 없음
