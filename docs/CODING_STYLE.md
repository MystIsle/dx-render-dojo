# 코딩 규약

기준 시점 : 2026-09-13

dx-render-dojo 의 C++ 코드 규약입니다. 코드를 쓰다가 걸리는 주제의 절만 찾아 읽으면 됩니다. 규약을 바꿀 때는 이 문서를 고칩니다.

이 문서에서 "원문"은 Rastertek DirectX 11 튜토리얼의 코드를 가리킵니다.

서식은 `.clang-format`, 네이밍은 `.clang-tidy` 로 검사합니다. 도구가 잡지 못하는 항목은 사람이 지킵니다.

## 1. 추상화

- 현재 튜토리얼이 요구하지 않는 추상화는 만들지 않음
- 중복은 3번째에서 뽑음

## 2. 소유

- COM 객체 : `ComPtr<T>`
- 내 객체 : `std::unique_ptr<T>`
- `shared_ptr` : 쓰지 않음
- raw 포인터·참조 : 빌리는 매개변수에만
- `new` / `delete` : 직접 호출 금지

해제는 `ComPtr` 와 `std::unique_ptr` 가 맡습니다. 그래서 `Shutdown` 계열 함수와 `SafeRelease` 는 쓰지 않습니다.

## 3. 초기화

- 멤버 : 헤더에서 기본 초기화
- 생성자·소멸자·복사생성자 : 쓰지 않음
- 복사 : `= delete`
- 실패할 수 있는 초기화만 `bool Initialize()`
- `Initialize` 는 직접 일함. `InitializeShader` 같은 내부 위임 함수 금지

## 4. 에러

- 실패 검사 : `CHECK_RETURN(expr, false)` 로 통일
- `if (FAILED(hr)) return false;` : 금지

## 5. 문자열

- 경로 : `std::filesystem::path` 또는 `const wchar_t*`
- 보관 : `std::wstring`
- const 가 아닌 `char*` : 금지

## 6. 네이밍

언리얼 컨벤션을 전면 채택합니다.

| 대상 | 접두 |
|---|---|
| 클래스·구조체 | `F` |
| 인터페이스 (순수 가상 함수만 있는 클래스) | `I` |
| 추상 클래스 | `A` |
| 템플릿 | `T` |
| enum | `E` |
| bool 변수 | `b` |

- 멤버·로컬·매개변수·함수·파일 : 모두 PascalCase
- 파일 이름 : 접두까지 클래스 이름과 같게 (`FModel` → `FModel.h`, `FModel.cpp`)
- 원문의 `Class` 접미사 : 떼고 접두를 붙임 (`ModelClass` → `FModel`)

`.clang-tidy` 가 잡지 못해 사람이 확인하는 것

- 파일 이름
- `T` 는 템플릿에만. 도구는 `T` 로 시작하는 클래스 이름을 검사하지 않음
- `I` 는 순수 가상 함수만 있는 클래스에만. 도구는 추상 클래스 중 `I` 로 시작하는 이름을 검사하지 않음
- bool 변수의 `b`. 도구는 `b` 로 시작하는 이름을 검사하지 않을 뿐, 그 변수가 bool 인지는 보지 않음

## 7. 헤더

- `#pragma once` 사용
- 매개변수 이름 : 항상 표기
- 한 줄 게터 : 인라인 `const`
- `using namespace` : 헤더에서 금지

## 8. 서식

- 중괄호 : Allman
- 들여쓰기 : 탭
- 줄 길이 : 120자 상한
- void 함수 끝 `return;` : 쓰지 않음
- 블록 뒤 빈 줄 2개 : 두지 않음
- 120자를 넘는 인자·매개변수 목록 : 한 줄에 하나씩
- 그 밖의 서식 : Microsoft 스타일 기본값

120자 상한은 학습 노트 때문입니다. 노트의 코드 블록은 가로 스크롤 대신 자동 줄바꿈되므로 긴 줄은 읽기가 깨집니다.

## 9. 기각안과 변경 이력

**기각안**

- `m_camel` : 번거로움
- `_Upper` : 예약어

**언리얼식 네이밍 채택 (2026-09-13)**

2026-08-23 에는 "멤버/로컬 구분이 약함" 을 이유로 기각했습니다. 2026-09-13 에 아래 이유로 채택했고, 구분이 약한 문제는 감수합니다.

- 스터디원이 언리얼 트랙 출신이라 접두 어휘가 독자에게 익숙함
- 회사 UE5 코드와 표기가 같아져 손에 익은 대로 쓸 수 있음

**이 문서로 옮기면서 정한 것 (2026-09-13)**

- 파일 이름에 접두 포함
- 추상 클래스 접두 `A` 추가. 인터페이스 `I` 는 순수 가상 함수만 있는 클래스로 한정
- `Shutdown` 계열도 `SafeRelease` 와 함께 은퇴
- 원문 이름과 새 이름의 대응 표는 두지 않음. 클래스를 분리하면 원문과 대응되지 않는 경우가 있기 때문. 필요해지면 참고용으로 이 문서 위나 아래에 추가
